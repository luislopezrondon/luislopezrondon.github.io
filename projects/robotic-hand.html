Overview

The hand can be controlled two ways. A data glove with five flex sensors measures how far each finger bends, and a computer vision mode tracks a hand on camera. Either way, an ESP32-S3 sends matching positions to five MG996R servos through a PCA9685 PWM driver, so the robotic hand mirrors the user's hand in real time.

The hand currently runs on a breadboard, and a custom PCB is in progress.

Version 1

This was the first version of the hand. I'm now reiterating with a more streamlined design.

Custom PCB (in progress)

The first PCB design was done in KiCad around an ESP32-WROOM-32. I'm now redesigning it in Altium around an ESP32-S3-WROOM-1U-N8R8, which adds native USB over USB-C.

The flex sensors sit on ADC1 (GPIO4–8), avoiding the GPIO3 strapping pin and the PSRAM pins (35–37). The PCA9685 is on I2C (GPIO1 SDA, GPIO2 SCL) with 4.7kΩ pull-ups, at address 0x40. The flex sensors connect through locking JST-PH connectors.

Power

The servos run from a DC power supply instead of a battery, which keeps the design simpler. A buck converter steps the supply down to a 6V servo rail.
