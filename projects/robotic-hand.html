Mimetic Robotic Hand

A five-servo robotic hand that mirrors a human hand in real time, controlled by both a flex-sensor data glove and computer vision.

Overview

The hand can be controlled two ways. A data glove with five flex sensors measures how far each finger bends. In computer vision mode, OpenCV running on a laptop tracks a hand through a camera and sends finger positions to the ESP32 over USB. Either way, an ESP32-S3 drives five MG996R servos through a PCA9685 PWM driver, so the robotic hand mirrors the user's hand in real time.

The hand currently runs on a breadboard, and a custom PCB is in progress.

Version 1

This was the first version of the hand, built on a breadboard. The biggest problem during testing was flex sensor connections coming loose. I'm now reiterating with a more streamlined design that gives the glove better support, with the flex sensors soldered directly to the PCB.

Custom PCB (in progress)

The first PCB design was done in KiCad around an ESP32-WROOM-32. I'm now redesigning it in Altium around an ESP32-S3-WROOM-1U-N8R8, which adds native USB over USB-C.

The flex sensors sit on ADC1 (GPIO4–8), avoiding the GPIO3 strapping pin and the PSRAM pins (35–37). The PCA9685 is on I2C (GPIO1 SDA, GPIO2 SCL) with 4.7kΩ pull-ups, at address 0x40.

Power

The servos run directly from a 6V bench power supply, and an AMS1117 regulator provides the 3.3V logic power for the ESP32-S3.
